# Monitor do programa e controles de mídia

## Organização do espaço de trabalho
O acervo de mídia mantém a navegação de arquivos e recebe as áreas de trabalho dedicadas: imagem, áudio, ferramentas e ajustes/propriedades. Os controles de imagem são divididos entre imagem, enquadramento e efeitos. O painel de áudio separa mixagem de trilhas, volume do clipe e fades. Os campos continuam ligados ao modelo existente do projeto; o motor de composição e a sincronização da timeline não são alterados.

## Monitor do programa
A barra de transporte usa duas linhas no desktop para manter tempo, reprodução, áudio, formato e reenquadramento visíveis. Ajustar preserva o quadro inteiro com a proporção do projeto; Preencher ocupa o monitor e pode cortar as bordas para evitar letterbox. Expandir canvas solicita tela cheia somente para a superfície do vídeo; os controles do editor ficam fora da área cheia. Escape sai da tela cheia.
